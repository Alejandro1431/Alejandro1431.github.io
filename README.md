# Portafolio

Sitio personal de Mario Alejandro Rebellón: **https://alejandro1431.github.io/**

Son tres archivos y una carpeta, sin build y sin dependencias: `index.html`,
`styles.css`, `script.js` y `cv/`. Se abre con doble clic en el navegador y se ve
igual que publicado, porque es lo mismo que sirve GitHub Pages desde la rama
`main`.

Los proyectos que aparecen son trabajo real. Los tres primeros puestos de la
sección de proyectos están reservados y vacíos a propósito: el HTML lleva un
comentario con la plantilla que hay que copiar para ocuparlos.
